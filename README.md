## 🌍 The Problem: Crisis in Hospitality
In high-density environments like hotels and hospitality hubs, emergency response is often crippled by **fragmented communication** and **information silos**. 
- **The Delay**: Every second lost in dispatching medical or fire services can be fatal.
- **The Chaos**: First responders lack real-time situational awareness of the building's layout and occupancy.
- **The Solution Challenge**: How do we use AI to synchronize national emergency protocols with local hospitality infrastructure?

## 💡 The Solution: AI CrisisSync
**AI CrisisSync India** is a "Single Pane of Glass" operations platform that bridges the gap between distress signals and emergency resolution. We leverage AI-driven classification and real-time telemetry to ensure the right resources reach the right location in record time.

## 🔥 Key Innovations

### 🧠 AI-Driven Severity Classification
Our custom NLP engine (simulated) analyzes incoming distress reports to automatically categorize emergencies. This prevents high-priority crises from being buried under minor incidents.

### 📍 Digital Twin & Grid Mapping
Using **Leaflet** and custom building telemetry, we provide a grid-based "System Map" that allows dispatchers to see exactly where an incident is occurring within a complex hospitality environment.

### ⚡ Autonomous Responder Synchronization
The system doesn't just track responders; it **synchronizes** them. Using proximity-based algorithms, the platform suggests the most efficient dispatch route and unit, minimizing travel time.

## 🛠️ Technical Excellence

### Architecture
- **Frontend**: React 19 (Latest stable) with Vite for ultra-fast HMR.
- **State Management**: Real-time polling architecture for live telemetry sync.
- **Animations**: Framer Motion for a fluid, high-fidelity "Control Room" experience.
- **Styling**: TailwindCSS 4.0 with a custom Cyber-Dark theme for reduced eye strain in mission-critical environments.
- **Backend**: Node.js/Express handling high-frequency status updates.

## 🚀 Installation & Deployment

1. **Clone the Project**
   ```bash
   git clone https://github.com/Shivam0400/Ai-CrisisSync.git
   cd Ai-CrisisSync
   ```

2. **Launch Backend**
   ```bash
   cd backend && npm install && node server.js
   ```

3. **Launch Frontend**
   ```bash
   cd ../frontend && npm install && npm run dev
   ```
