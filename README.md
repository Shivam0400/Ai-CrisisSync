## 📖 Overview

**AI CrisisSync India** is a high-fidelity, real-time emergency management platform designed to synchronize crisis response. Developed for the hackathon problem statement focusing on **Rapid Crisis Response in Hospitality**, the platform provides a unified operations dashboard for emergency dispatchers, field responders, and administrators.

The system leverages AI to classify incoming incidents by severity, automates responder assignment based on proximity and status, and provides a "Single Pane of Glass" view of the entire emergency landscape.

## ✨ Key Features

- **🛡️ Live Operations Dashboard**: Real-time monitoring of active incidents with high-visibility alerts.
- **🗺️ Interactive System Map**: Grid-based building mapping and location tracking using Leaflet.
- **🤖 AI Incident Classification**: Automated severity assessment (Critical, High, Medium, Low) for faster prioritization.
- **⚡ Dynamic Dispatch**: Intelligent responder assignment and status tracking (En Route, On Site, Resolved).
- **🧪 Crisis Simulations**: A dedicated environment to test emergency protocols and responder efficiency.
- **🌓 Adaptive UI**: Fully responsive design with glassmorphic aesthetics and dark/light mode support.
- **🔔 Smart Notifications**: Real-time toast notifications for critical updates and dispatch status.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 + Vite
- **Styling**: TailwindCSS (Modern Dark Theme)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Maps**: React Leaflet
- **Routing**: React Router Dom

### Backend
- **Server**: Node.js + Express
- **Middleware**: CORS
- **API**: RESTful architecture for status and data synchronization

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shivam0400/Ai-CrisisSync.git
   cd Ai-CrisisSync
   ```

2. **Setup the Backend:**
   ```bash
   cd backend
   npm install
   node server.js
   ```

3. **Setup the Frontend:**
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```

The application will be available at `http://localhost:5173`.
